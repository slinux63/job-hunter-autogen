# job-hunter-autogen

A local AI job-hunting assistant built with Python, AutoGen-style agent architecture, and a local LM Studio model.

This starter project is designed to:
- collect public job offers from sources such as Indeed, Welcome to the Jungle, and custom RSS/search pages
- analyze a CV / candidate profile
- score job fit for each offer
- organize daily summaries and work items for applications
- run locally with a model served by LM Studio

Important note:
- LinkedIn scraping is not recommended because of platform restrictions and terms of use.
- This project focuses on public sources and supported job boards, and keeps the workflow local and privacy-friendly.

## Core features
- local LLM via LM Studio
- multi-agent architecture
- public source collection script
- scoring of applications against a CV
- daily digest generation
- SQLite data store for offers, applications, and summaries

## Quick start

1. Install LM Studio and load a local model.
2. Enable the local API server in LM Studio.
3. Clone the project and install dependencies.
4. Copy `.env.example` to `.env` and adjust values.
5. Run the app:

```bash
python -m job_hunter.main --keywords "python backend" --location "Paris" --limit 10
```

## Environment variables

```bash
LMSTUDIO_BASE_URL=http://localhost:1234/v1
LMSTUDIO_MODEL=mistral
JOB_KEYWORDS=python backend
JOB_LOCATION=Paris
DB_PATH=data/job_hunter.db
```

## Recommended workflow

1. Add a CV in `data/cv.md`.
2. Configure your search keywords and location.
3. Let the scraper fetch public job offers.
4. Score each offer against your profile.
5. Read the generated digest and decide which applications to target.

## Notes

This project is intentionally a starter. For production use you may want to add:
- real authentication for source-specific APIs
- PostgreSQL instead of SQLite
- a scheduler (cron/systemd)
- a proper UI
- stronger filtering for job board rules and anti-bot protections
